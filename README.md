# だれの ものがたり？ ～ひとびと伝説～

Unity製DQ風RPG（HTML/JS版からの移植）。7視点のキャラクターを切り替えながら進める小さな冒険。

## どんなゲーム？
勇者/村人B/そんちょう/大臣/祠で待つ人/ぴちぴちギャル/牢屋のごろつき、7人の視点で同じ世界を冒険する。勇者でクリアすると「だれの ものがたり？」のタイトルに戻り、別キャラの場所から再開できる。

- 村4つ（はじまり/みなと/たかね/ヨイヤミ）、洞窟・祠・魔王城
- セーブ/ロード（4スロット+オートセーブ）
- ジェネラティブBGM（外部音源なし、リアルタイム生成で10曲）
- キーボード・ゲームパッド（Switch Pro/Hori等）対応

## 操作
- 移動: 矢印キー/WASD、ゲームパッドの十字キー/左スティック
- 決定: Z/Enter/Space、ゲームパッドのA系ボタン
- キャンセル/メニュー: X/Escape、ゲームパッドのB系ボタン
- はしる: Shift、ゲームパッドのL/R/ZL/ZR

## ビルド
`Assets/Editor/TitanBuild.cs` の `Titan/Build Web` でWebGL出力。
